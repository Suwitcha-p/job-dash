# AI & Data Science Labor Market & Skill Mismatch Analysis

โครงการวิเคราะห์ระบบนิเวศแรงงานและตลาดงานด้าน AI, Data Science และ Statistics รวบรวมข้อมูลอุปทาน (ผู้สำเร็จการศึกษา/หลักสูตร) อุปสงค์ (ตำแหน่งงานว่าง/ทักษะที่ต้องการ/เงินเดือน) และการวิเคราะห์ Skill Mismatch

## 📂 Open Data Sources (แหล่งข้อมูลเปิด)

1. **Stanford AI Index Report Public Data**
   * สถิติจำนวนผู้สำเร็จการศึกษาระดับปริญญาตรี โท และเอก ด้าน AI & CS ทั่วโลก
   * [ดาวน์โหลดข้อมูล](https://hai.stanford.edu/ai-index)
2. **Kaggle: AI & Data Science Job Market Dataset (2020–2026)**
   * ประกาศรับสมัครงานกว่า 10,000+ รายการ ระบุวุฒิการศึกษาและทักษะที่ต้องการ
   * [ดาวน์โหลดข้อมูล](https://www.kaggle.com/datasets/shree0910/ai-and-data-science-job-market-dataset-20202026)
3. **Kaggle: Data Science, AI & ML Job Salaries Dataset**
   * ฐานเงินเดือนและโครงสร้างค่าตอบแทนในสายงานข้อมูลทั่วโลก
   * [ดาวน์โหลดข้อมูล](https://www.kaggle.com/datasets/adilshamim8/salaries-for-data-science-jobs)
